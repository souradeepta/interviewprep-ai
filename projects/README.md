# Curriculum Capstones

These four local projects turn the role paths into reviewable evidence. Each is designed for 6–10 focused hours, uses deterministic synthetic data, defines a runnable success check, and has a 100-point rubric. Choose the capstone linked by your role path in the [curriculum map](../roadmaps/curriculum-map.md).

| Project | Focus | Timebox | Main lesson links |
|---|---|---:|---|
| [01. Tabular ML in production](01-tabular-ml-production.md) | Leakage-safe modeling, calibration, and release checks | 8 hours | [ML evaluation](../ml/concepts/evaluation-metrics.md), [data leakage](../ml/concepts/data-leakage.md) |
| [02. RAG evaluation and retrieval](02-rag-evaluation-and-retrieval.md) | Evidence retrieval, answerability, and reproducible evaluation | 8 hours | [RAG](../llm/concepts/18-rag.md), [retrieval systems](../llm/concepts/40-retrieval-systems.md) |
| [03. ML platform reliability](03-ml-platform-reliability.md) | Data contracts, monitoring, incident handling, and rollback | 8 hours | [Data pipelines](../mlops/concepts/01-data-pipelines.md), [monitoring](../system-design/patterns/16-monitoring-and-observability.md) |
| [04. Agent workflow safety](04-agent-workflow-safety.md) | Bounded tools, idempotency, abstention, and audit traces | 8 hours | [Agent loops](../agentic-ai/concepts/02-agent-loops.md), [agent testing](../agentic-ai/concepts/28-agent-testing.md) |

Use the shared [scorecard](scorecard.md) to structure review and the project-specific rubric to award points. The local success check verifies the stated behavior only; it does not certify a production deployment.
