# ML Interview Prep

How to use:
1. **Simulate the interview** — cover the question, draft your answer, then reveal.
2. **Time yourself** — theory: 3–5 min. Coding: 20–30 min. Case studies: 45 min.
3. **Work all 6 steps** — don't skip to the answer.

Files:
- [ML Theory Questions](ml-theory-questions.md) — 56 Q&A, including applied evaluation decisions
- [ML Coding Questions](ml-coding-questions.md) — 20 ML, data, retrieval, and evaluation prompts
- [Data/SQL Questions](data-sql-questions.md) — SQLite-compatible feature and experiment drills
- [Evaluation Questions](evaluation-experiment-questions.md) — classical ML, ranking, experiments, LLM, and agent evaluation
- [ML Case Studies](case-studies.md) — end-to-end 45-minute system design scenarios
- [Solutions](solutions/) — deterministic NumPy/Python reference implementations
